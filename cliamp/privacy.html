Privacy Policy — cliamp

Last updated 8 September 2026

The short version. This is a single-person desktop setup. It reads one person’s own YouTube playlists onto that person’s own computer, read-only. Nothing is uploaded, stored on a server, shared, or sold. There is no backend to leak.

What this covers

This policy covers the Google OAuth client named cliamp (Google Cloud project cliamp-507800), operated by Daryll Gomas of Big Pic Solutions, Portland, Oregon.

cliamp itself is independent open-source software (MIT licensed) written by a third party. It is a terminal music player. This OAuth client is a personal deployment of it: it exists so that one operator’s own copy of cliamp can list that operator’s own YouTube Music library instead of showing an empty screen.

What is accessed

Exactly one scope is requested:

  • https://www.googleapis.com/auth/youtube.readonly — read-only access to the signed-in Google account’s own YouTube data.

In practice, the only data read is the account’s playlist names, liked music, and the titles of tracks inside those playlists, so they can be listed and played back.

The scope is read-only. This client cannot upload, comment, subscribe, delete, modify a playlist, or change anything at all on the account.

Where the data goes

Onto the operator’s local computer, and nowhere else. Specifically:

  • Playlist and track listings are fetched from Google’s API directly by the desktop application and held on that machine — cached at ~/.config/cliamp/ytmusic_cache.json.
  • The OAuth refresh token is written to ~/.config/cliamp/ytmusic_credentials.json on that same machine.

There is no server component. Big Pic Solutions operates no service that receives this data. No copy is transmitted to Big Pic Solutions, to any analytics provider, to any advertiser, or to any other third party. Nothing is sold, rented, or used for training. There is no tracking, no telemetry, and no profiling.

Who can use this client

One person: the operator, signing in with his own Google account. This is not a product, a service, or a hosted application, and it is not offered to the public.

Retention and deletion

Data persists only as local files, and only until they are deleted. Deleting the ~/.config/cliamp/ folder removes the cached library and the stored token immediately and completely.

Revoking access

Access can be withdrawn at any time, without contacting anyone, at myaccount.google.com/permissions. Revoking invalidates the stored token; the application then simply shows an empty library.

Limited Use

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Data obtained through this client is used solely to display and play the operator’s own music library in the operator’s own music player, and is never transferred to others, used for advertising, or read by humans.

Changes

If this policy changes, the revision date above changes with it.
